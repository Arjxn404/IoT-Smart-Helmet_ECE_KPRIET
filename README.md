# 🪖 IoT Smart Helmet — Industrial Worker Safety Monitoring System

## Overview

The IoT Smart Helmet is an embedded worker-safety monitoring system developed using the Silicon Labs BRD2605A (SiWx917) development board. The system monitors workplace safety conditions such as gas levels, temperature, humidity, and accidental impacts or falls, while providing wireless communication and web-based monitoring.

## Key Features

* Worker Safety Monitoring
* Impact / Fall Detection
* Gas-Level Monitoring
* Temperature and Humidity Monitoring
* Wi-Fi 6 Connectivity
* Bluetooth Low Energy (BLE)
* Cloud / Data Communication
* Web-Based Monitoring Dashboard
* Hazard Status Evaluation

## Hardware Platform

* Silicon Labs BRD2605A (SiWx917)
* MPU6050 Accelerometer / Gyroscope
* MQ-135 Gas Sensor
* DHT22 Temperature & Humidity Sensor
* Li-ion Battery
* Smart Helmet

## Technologies Used
